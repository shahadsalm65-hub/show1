# MYSPACE — Personal Portfolio

موقع معرض أعمالي الشخصي بالعربية والإنجليزية، مبني بـ HTML5 وCSS3 وJavaScript خالص.

## الهيكل

```
index.html          الصفحة الرئيسية
projects.html       معرض المشاريع
contact.html        صفحة التواصل
assets/css/style.css   نظام التصميم والأنماط
assets/js/main.js       الترجمة والتفاعلات
صوره الاول.jpg        الصورة الأصلية — متجر الورد
1630321545530.jfif   الصورة الأصلية — المدن الذكية
```

## تشغيل الموقع محليًا

افتح أحد الملفات مباشرة في المتصفح، أو شغّل خادمًا محليًا من داخل المجلد:

```powershell
# PowerShell
python -m http.server 8000     # إن كان Python متاحًا
# ثم افتح http://localhost:8000
```

## اللغة

- العربية هي الافتراضية مع اتجاه RTL، والإنجليزية مع LTR.
- زر `AR / EN` متواجد في رأس كل صفحة، ويُحفظ الاختيار في `localStorage` لكل الصفحات.
- النصوص كلها في كائن `I18N` داخل `assets/js/main.js`، ويمكن تعديلها من مكان واحد.

## الروابط والبيانات القابلة للتعديل

- روابط المشاريع موجودة مباشرة على الأزرار في `projects.html` (تعمل حتى بدون JavaScript):
  - متجر الورد: `https://flower.shahadsalm65.workers.dev`
  - المدن الذكية: `https://project.shahadsalm65.workers.dev`
- البريد الإلكتروني وروابط منصات التواصل في أعلى `assets/js/main.js` (`CONTACT_EMAIL` و`SOCIALS`).
- الضغط على صورة المشروع يفتحها بحجمها الأصلي في نافذة عرض (Lightbox).
